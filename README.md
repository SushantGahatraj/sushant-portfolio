# Sushant Gahatraj — Portfolio

A responsive personal portfolio built with Next.js, React, and TypeScript.

## Run locally

Install Node.js 20.9 or newer, then run:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build for production

```bash
npm run build
npm run start
```

## Customize

The site content is in `app/page.tsx`, while the complete visual system and responsive styling live in `app/globals.css`.
